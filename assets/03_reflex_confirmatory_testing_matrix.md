# Reflex And Confirmatory Testing Matrix

Title: Laboratory Matrix For Rapid MDRO Result Status, Confirmation, Communication, And Follow-Up

Author: Marious Akugri

Version: 1.0 public reference release

Date: 2026-08-25

## Summary

This matrix provides synthetic, laboratory-scoped examples for handling rapid MDRO-related result signals. It is designed to help laboratories distinguish preliminary, final, corrected, pending, and confirmation-dependent findings before communication or follow-up.

This artifact is not a testing menu, treatment guide, institutional policy, or public-health reporting directive. It is a reference framework that laboratories may adapt under local validation, regulatory, medical director, laboratory director, infection prevention, antimicrobial stewardship, and quality oversight.

The matrix uses "confirmatory" and "validation" language in the ordinary laboratory-review sense. It does not claim that Marious Akugri has clinically validated a test method, implemented this matrix in a hospital, or obtained institutional approval for any live workflow.

## How To Use This Matrix

Use the matrix to ask four laboratory questions:

1. What type of result or trigger is present?
2. What is the result status?
3. What laboratory follow-up may be needed?
4. What communication or documentation step may be appropriate under local policy?

All examples are synthetic. Local policies, approved methods, validation/verification records, and institutional governance control actual testing and communication.

## Status Language Controls

Use status-aware language.

| If The Result Is... | Safer Comment Logic |
|---|---|
| Preliminary | State that the rapid/preliminary result was detected and that culture/AST/final identification may be pending. |
| Final | State final laboratory result status without treatment recommendation. |
| Corrected | State that a corrected result has been issued and follow local corrected-result notification policy. |
| Pending confirmation | State that additional confirmation or characterization may be pending under local policy. |
| Discrepant | Route for technical review and follow local discrepancy/corrected-reporting process. |

## Communication Priority Categories

This matrix does not define mandatory priority levels. A laboratory can adapt categories such as:

| Category | Description | Example Documentation Need |
|---|---|---|
| Routine result follow-up | Result does not meet urgent criteria but requires final-status tracking. | Final review complete, comment applied if applicable. |
| Urgent/critical notification | Result meets local urgent or critical communication policy. | Recipient, time, route, and staff documentation. |
| Infection prevention awareness | Result may affect isolation, containment, or transfer communication. | Route or queue used, time, and final-status follow-up. |
| Stewardship awareness | Result may be reviewed by antimicrobial stewardship under local process. | Route used and result status noted. |
| Technical review | Result is unusual, discrepant, corrected, or confirmation-dependent. | Supervisor/director review and follow-up action. |

## Synthetic Example: C. auris Identification Concern

```text
Trigger:
A yeast isolate is identified by a method that may have C. auris misidentification limitations.

Status:
Identification concern, not confirmed C. auris.

Laboratory check:
Review identification method, result confidence, organism context, and local confirmation pathway.

Possible follow-up:
Use approved confirmatory method or referral route if local criteria are met.

Communication:
Route to laboratory supervisor/director and infection prevention according to local policy.

Comment boundary:
Do not label the isolate as confirmed C. auris until confirmation criteria are satisfied.
```

## Synthetic Example: Rapid Resistance Marker With AST Pending

```text
Trigger:
Rapid molecular testing detects a resistance marker from a positive blood culture bottle.

Status:
Preliminary rapid molecular result. AST pending.

Laboratory check:
Confirm result review/QC status and reporting criteria.

Possible follow-up:
Track final organism identification and AST.

Communication:
Use local urgent/critical notification route if applicable. LIS comment should state that culture and/or AST may be pending.

Comment boundary:
Do not provide treatment selection or imply final phenotypic susceptibility before AST is finalized.
```

## Quality Review Checklist

Before adapting this matrix, check:

- Does each row distinguish result status?
- Is every communication action tied to local policy?
- Are preliminary and final results clearly separated?
- Does every confirmation-dependent result avoid overstatement?
- Are public-health reporting references limited to local/state/federal rules and institutional process?
- Are clinical treatment decisions excluded?
- Are all examples synthetic?
